# Sameer Verma

I build developer tools, apps that work over local networks, and embedded systems. I like projects that start with a concrete problem and end with something people can try.

## Selected projects

- **[reuse-first](https://github.com/beingaeditor/reuse-first)** — A Python tool that helps you find existing open-source projects and use their structure as a starting point.
- **[Eluno](https://github.com/beingaeditor/Eluno)** — A prototype for moving files between devices on the same network.
- **[VanSetu](https://github.com/beingaeditor/VanSetu)** — A geospatial planning tool that identifies heat-exposed walking routes in Delhi and compares ways to cool them.
- **[ROBOT-ARM](https://github.com/beingaeditor/ROBOT-ARM)** — STM32 firmware for a three-axis robot arm, with servo control, kinematics, and ultrasonic sensing.
